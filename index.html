Canvas Outliner — 동작·UI/UX 전체 검수 시안

확정 요구사항 65개 · SVG 65개 · 수용 테스트 65개. 실제 Obsidian에서 동작하는 플러그인이 아닌 독립형 기획 시뮬레이션입니다. SVG의 도형 크기·위치·색상은 개념 설명용입니다.

3개 구조작동 예시도식추적검증 필요

1. 원본 Canvas / 가상 Collection / Presentation 구분

실제 Canvas

Group A └── Card A (등록됨) Card B (미등록)

실제 Group 내부 관계는 Canvas를 기준으로 함

Outliner Space

Collection: 캐릭터 자료 └── Group A (여기선 펼침 없음) 실제 Group 계층 └── Group A └── Card A

Collection 참조의 Group은 펼치지 않음(Q02). 일반 Card는 등록된 것만 표시.

Presentation Space

1. Card A 2. Presentation Group 1 3. Card A (같은 원본)

Presentation Group은 `.canvas` 노드가 아닌 Plugin Data 전용 영역.

2. 직접 눌러 확인하는 대표 시연

모든 조작은 이 페이지의 임시 상태만 변경하며 Vault/Canvas 원본에 접근하지 않습니다.

Item 등록 / 선택 / 화면 맞춤

Group A └── Card A (등록) Card B (미등록 / 숨김)

Canvas View: 전체

Collection 참조 이동 / Ctrl 추가

Collection 참조만 바뀌며 실제 Card와 Group 좌표는 유지됩니다.

정렬 방식

자동 정렬 중에는 순서 드래그 제한. Custom 순서 독립 저장.

Presentation 방향키 시연

Card A

Presentation View 효과

시각화는 발표 ON/OFF와 독립적. 효과 영역은 예시.

Remote Presentation Map

Map 보기

Canvas 축소 배치 + 등록 위치 번호. 버튼은 시뮬레이션 이동.

Canvas Search

검색어 및 필터 변경 시 갱신. 실제 MD 내부 정확 이동은 미검증.

삭제 및 복구

삭제 UI 숨김 / 복구는 현재 Canvas 작업 세션만.

5. 한계 / 기술 미검증 항목

아래는 실제 Obsidian Windows 환경에서 실행 검증을 완료한 사항이 아닙니다. HTML의 인터랙션은 명세 시뮬레이션일 뿐입니다.

  • Canvas Node 고유 ID 삭제·Undo 재결합 및 중첩 Group 소속 판정
  • 외부 파일 관리자 복제 시 별도 Plugin Data 함께 복제 감지
  • Card 내부 Heading·Line 정확 위치 이동, 임시 Highlight
  • 다른 플러그인의 Canvas UI 렌더·Pan·Zoom 충돌 없는 동작
  • 대형 Canvas 실시간 검색·지도·렌더링 성능
